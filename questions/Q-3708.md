> 在面栈阅读：[大模型为什么会产生幻觉？](https://mianstack.com/question/q-3708)

## 核心回答

大模型产生幻觉，根本上与**统计生成目标和事实验证之间的差距**有关。模型根据训练中学到的规律和当前上下文预测后续内容，并没有在每生成一句话时自动查询一个完整、实时且可溯源的事实库。知识缺失、数据错误、上下文利用失败或推理偏差，都可能使“看起来合理”的续写变成错误结论。

后训练和评测的激励也有影响：如果“猜对有分，承认不知道没分”，系统可能更倾向在不确定时给出答案。解码随机性和应用链路中的检索、摘要、工具错误会进一步影响输出，但幻觉并不是只由高 `temperature` 造成。

## 训练阶段为什么留下知识缺口？

预训练主要学习文本分布。常见语言模式有大量重复证据，模型容易学到；某个冷门人物的生日、内部制度或刚发生的事件，可能没有足够资料，也无法从一般规律推导。

训练语料还可能包含错误、过时事实与互相冲突的说法。模型将知识分布在参数中，并不天然保存一条清楚的“事实—出处—有效期”记录，因此检索参数知识时可能混淆实体、日期和事件。

不过，不能把问题全归咎于脏数据。相关研究在简化设定下说明，即使训练数据无错，统计学习和有限证据也可能产生生成错误；其中关于特定事实分布的理论结论，不等于每个模型在所有任务上都有同一个幻觉率。

## 知道过正确答案，为什么仍可能答错？

“训练中有过”不等于当前调用一定正确使用。模型可能受问题中的错误前提影响，忽略限定条件，误解否定句，或在长上下文中被相似内容干扰。生成中一旦先写出了错误实体或推断，后续文本还可能沿着这条错误前提继续展开。

例如材料先写“发布样机”，后面另有“尚未商业交付”。若模型只采用前一句并补全常见商业报道的写法，就可能写成“已经规模交付”。这是信息利用和推断越界，不能简单解释成没有相关知识。

## 激励和解码分别起什么作用？

后训练可以改善指令遵循与不确定性表达，但优化目标的设计很重要。若偏好数据更奖励完整、肯定的回答，或主要评测把合理拒答与错误回答都记为零分，就可能弱化“不确定时少说一点”的收益。并不是所有后训练都必然鼓励幻觉，奖励和评测也可以专门支持正确澄清与保守回答。

采样策略改变候选 token 的选择方式。提高随机性可能使输出更多样，也可能偏向缺乏证据的细节；采用更确定的解码仍然只是从模型当前分布中选择，最可能的文本也可能是错的。token 概率描述续写倾向，不等于某个事实为真的概率。

## 接入RAG和工具后，又增加了哪些原因？

| 环节         | 可能出现的问题                                   |
| ------------ | ------------------------------------------------ |
| 资料与解析   | 版本过期、表格条件丢失、主体混淆                 |
| 检索与筛选   | 正确证据未召回，相似但不适用资料进入输入         |
| 上下文与摘要 | 否定条件、日期或最新更正被裁掉                   |
| 工具与执行   | 超时或部分失败被误读成成功，返回值被错误转述     |
| 最终生成     | 证据只有计划，答案扩成既成事实；引用与结论不对应 |

这些环节有时先造成证据错误，再被模型放大。排查要保存当时的完整输入和工具返回，定位第一处偏离；再分别改数据、检索、上下文、提示或验证规则。单纯增加检索数量、降低温度或换一个更大模型，未必能解决发生在其他环节的问题。
