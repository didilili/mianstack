> 在面栈阅读：[如何自行实现 ReAct，框架实现与手写实现的边界是什么？](https://mianstack.com/question/q-3965)

## 核心回答

手写 `ReAct` 的核心是把**模型决策、工具执行、观察回填和停止判断**组成闭环：模型根据当前目标与历史结果提出下一步，程序校验并执行工具，把真实结果交回模型，模型再决定继续还是给出最终答案。

实现时先统一消息和工具协议，再用受预算约束的循环驱动。每轮模型返回最终回答或结构化工具调用；执行器检查工具名、参数与权限，调用实际函数，并按调用ID把结果写回消息。次数、时间、取消和最终验收由程序控制。经典 `Thought/Action/Observation` 文本可以帮助理解，但现代工具调用协议更容易可靠解析，也不要求获取模型隐藏的思维链。

框架能复用模型适配、消息类型、工具分发、状态、流式事件和检查点；业务工具、数据权限、幂等策略及完成标准仍需自行实现。

## 手写时要落实哪些步骤？

### 1. 先定义消息与工具契约

工具注册表保存工具名称、用途、参数 Schema、执行入口，以及是否只读、超时和结果格式。只把模型允许看到的工具定义放入请求。

模型适配器负责把厂商响应转换为内部格式，例如“最终文本”或“工具调用列表”。每次调用都有唯一ID，保留模型的工具调用消息，再为每个调用写入匹配ID的结果消息。一轮多个工具可以在相互独立且执行策略允许时并行；依赖前一个返回值的调用应分轮执行。

### 2. 驱动循环并回填观察

可以把主体写成下面的伪代码。`model_call`、`execute_checked` 和 `save_step` 表示适配器、受控执行器与状态存储，不是某个 SDK 的现成API。

```text
保存用户消息
在剩余步数、时间和费用允许时：
    检查取消信号
    response = model_call(当前消息, 可用工具)
    保存模型消息
    若response没有工具调用：
        验证输出，返回结果或明确的未完成状态
    对每个工具调用：
        result = execute_checked(名称, 参数, 调用ID)
        保存与调用ID匹配的工具结果
    保存本轮状态与实际消耗
超出预算：保存已有结果，以“预算耗尽”结束
```

工具异常也要形成可处理的反馈。参数缺少必填项可以返回明确的字段错误，让模型修正；权限拒绝不应通过换提示词重试；网络瞬时故障在执行器内做有限重试，消耗计入整体预算。

### 3. 把错误恢复和停止做在循环外侧

只检测“没有工具调用”还不够：模型可能在证据不足时结束，也可能一直调用同一个失败工具。应用应检查目标所需字段、产物和证据，记录重复动作与进展，并设置总截止时间。

模型调用流中断时，不完整的工具参数不能执行。工具已经产生外部副作用、结果回填前宕机时，则通过业务幂等键和回执核对恢复。`tool_call_id` 用于消息关联，不天然等于外部系统支持的幂等键。

## 框架与手写分别适合什么情况？

| 方面 | 手写时需要承担                           | 框架可复用的部分                  |
| ---- | ---------------------------------------- | --------------------------------- |
| 协议 | 适配模型响应、拼装工具结果、聚合流式参数 | 标准模型与消息、工具接口          |
| 执行 | 循环、条件分支、异常和预算传播           | Agent循环、节点、工具执行与中间件 |
| 状态 | 消息、动作与结果、检查点、恢复位置       | 状态图、`Checkpointer`、中断恢复  |
| 业务 | 工具实现、鉴权、幂等、结果验收           | 可用扩展点，规则仍由应用定义      |

只需少量只读工具、执行链很短时，手写便于看清行为。涉及多模型、长任务、人工中断和追踪时，可以把通用部分交给框架，再定制节点与执行边界。判断依据是控制需求和维护成本。

## 常见追问

**用 `Function Calling` 就是在做 `ReAct` 吗？**

一次函数调用只完成动作表达与执行接口。把工具返回作为观察，再驱动后续模型决策，才形成这里讨论的行动反馈循环；固定代码也可以调用工具，并不自动成为`ReAct`。

**如何验证手写循环是对的？**

先用可控的模型替身回放“请求工具 → 读取结果 → 最终回答”，检查消息ID关联和执行次数，再覆盖未知工具、坏参数、工具异常、取消和预算耗尽。之后用真实模型检查工具选择和完成质量；替身测试不能证明模型效果。
