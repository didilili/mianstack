> 在面栈阅读：[分类模型应如何选择和解释 Accuracy、Precision、Recall、F1、ROC 与 AUC？](https://mianstack.com/question/q-5342)

## 核心回答

先明确哪个类别是“正类”、分数越大是否越像正类，再区分两件事：**固定阈值后的业务结果**与**模型对样本的排序能力**。

- Accuracy看全部样本中判对多少；类别不平衡时，多数类可能掩盖少数类失败。
- Precision看“预测为正的样本中，有多少真的为正”，关注误报；Recall看“实际正样本中，有多少被找出”，关注漏报。
- F1是Precision与Recall的调和平均，适合同时关注两者，但不计TN，也不直接表达不同业务代价。
- ROC扫描阈值得到FPR–TPR曲线，ROC-AUC概括正负样本的排序能力。它不决定上线阈值；少数正类场景还要看PR曲线、AP或约定口径的PR-AUC。

选择时把目标具体化，例如“Recall至少90%时Precision最高”，或“误报处理成本与漏报损失之和最小”，在验证集选阈值，再用独立测试集报告结果。

## 混淆矩阵和公式

TP为真实正且预测正，FP为真实负却预测正，FN为真实正却预测负，TN为真实负且预测负：

```text
Accuracy = (TP+TN)/(TP+FP+FN+TN)
Precision = TP/(TP+FP)
Recall = TPR = TP/(TP+FN)
F1 = 2PR/(P+R) = 2TP/(2TP+FP+FN)
FPR = FP/(FP+TN)
```

Precision分母是预测正，Recall分母是真实正；中文“准确率”有时被误用来指Precision，面试时最好同时报英文名和分母。若相应分母为0，要说明无定义或工具采用的零分处理约定，不默认为模型完美。

## 类别不平衡的可复算例子

1000笔交易中有10笔欺诈，以欺诈为正类。假设模型抓住8笔、漏2笔，并把18笔正常交易误报为欺诈：

| 项目           | 数值          |
| -------------- | ------------- |
| TP、FN、FP、TN | 8、2、18、972 |
| Accuracy       | 980/1000=98%  |
| Precision      | 8/26≈30.77%   |
| Recall         | 8/10=80%      |
| F1             | 16/36≈44.44%  |
| FPR            | 18/990≈1.82%  |

全部判正常的模型Accuracy为99%，比上例还高，但Recall为0，无法抓欺诈。上例FPR仅1.82%，人工却要处理26个告警，其中18个是误报：这说明正类稀少时，只看ROC上的低FPR仍可能低估实际处理负担。

## ROC-AUC与PR分别告诉什么

ROC横轴FPR，纵轴TPR。将阈值从高降到低，依次把更多样本判正得到曲线。对于正负样本都存在的测试集，AUC可理解为随机取一个正样本和一个负样本，正样本分数更高的概率；同分按半次胜出处理。

例如分数降序为 `0.9正、0.8负、0.7正、0.1负`，共有2×2=4对正负组合，正样本胜出3对，所以ROC-AUC=0.75。阈值取0.8（分数≥0.8判正）时Precision=Recall=0.5、F1=0.5；阈值取0.7时Precision=2/3、Recall=1、F1=0.8。改变阈值改变标签结果，不改变这组分数的AUC。

PR横轴Recall、纵轴Precision，直接呈现找出多少正例以及结果有多纯。正类越稀少，同样TPR/FPR下Precision通常越低；随机排序的Precision基线由正类比例决定。ROC-AUC在类别条件分数分布不变时不因类比例本身改变，PR会显著受其影响，但分布变化仍可能改变两者。

AP按每次Recall增量加权Precision，上面例子为 `(1+2/3)/2=5/6≈0.8333`。梯形积分的PR-AUC与AP并不总相同，汇报时需明确实现。AUC也不是准确率或概率校准质量：严格递增变换保持排序，却可能改变分数含义。

## 多分类、选阈值与业务追问

多分类可逐类算准召，并报告macro、micro或weighted口径：macro每类等权，micro先汇总TP/FP/FN，weighted按各类样本量加权。类别不平衡时只报weighted平均也可能掩盖长尾类，应附每类support与关键类别表现。多标签则通常还需逐标签阈值，不能仅取最大分数。

漏报代价高时，可在误报预算或最低Precision约束下提高Recall；误报昂贵时，可在最低Recall下提高Precision。F1最大不等于成本最低，0.5也不是通用最优阈值。若分数已校准、误报成本为Cfp、漏报成本为Cfn且其他条件符合二分类决策假设，阈值可由成本关系推导；实际仍要用独立数据检查校准和分布漂移。

阈值、模型和特征都不要在最终测试集上反复挑选。还应按时间、渠道和人群分组检查，尤其核对正类标记与预测分数方向；把正常概率当欺诈概率会把排序结论颠倒。
