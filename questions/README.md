# 题目目录

本目录保存整理后的标准面试题。每个 `Q-*.md` 文件包含机器可读的 JSON frontmatter，以及可选的参考答案正文。

- 题目标题、分类、难度、准备优先级和答案状态以当前文件为事实来源。
- 可以直接修正题目或答案；已有题号不得重排或复用。
- 字段结构与固定取值见 [`schema/README.md`](../schema/README.md)，最小写法见 [`examples/question.example.md`](../examples/question.example.md)。
- 浏览题目请从[题库总索引](../INDEX.md)进入；贡献前请阅读[贡献指南](../CONTRIBUTING.md)。
