# 公开题集目录

本目录保存公开题集的原题、来源、作者与必要的阅读说明，每份题集一个 `COL-*.json` 文件。对应标准题的匹配与分段编排由网站单独维护。

题集的 `readingUrl` 是根据 ID 自动生成的面栈阅读链接；`sourceUrl` 保留第三方原题集链接。
