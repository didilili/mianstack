## 原帖正文

> 8.21一面
> 1. 先做一下自我介绍吧。
> 2. 你在项目中做过性能优化吗？能讲一下从性能问题发现到问题解决的完整链路吗？
> 3. 流式问答的技术选型会考虑哪些维度？为什么选择基于 Fetch 的 Server-Sent Events，而不是原生 SSE 或 WebSocket？
> 4. 你的多会话流式管理主要是怎么实现的？
> 5. 流式过程中渲染大量 Markdown 时，如何优化卡顿问题？
> 6. 你的 RAG 召回率提升了大约 20%，主要做了哪些工作？
> 7. 如果向量库中的文档被更新或删除，你会怎么做版本管理？
> 8. 你了解 Web Coding 或 AI Coding 吗？项目中大概有多少代码是手写的，多少代码是 AI 辅助完成的？
> 9. 如何保证 AI 生成代码的可维护性、正确性和编写逻辑？
> 10. 如何判断哪些模块需要人工检查、哪些模块由 AI 检查就够了？如果希望用 AI 检查，怎样增强对检查结果的可信度？
> 11. 如果从前端转向全栈，参与线上重要项目，你会如何规划后端知识的学习？又如何保证 AI 写出的后端代码可用且没有问题？
> 12. 当你不太熟悉数据库和 SQL 时，需要设计查询和数据库操作，你会怎么做？会先学习还是让 Agent 辅助？
> 13. 如果让 Agent 帮你写 SQL，如何验证它不会导致慢查询或超时？你会怎么规避？
> 14. 笔试题可以选择手写或 Web Coding，你选择哪一种？
> 15. 手写一个 async pool 函数：接收最大并发数和请求地址数组，控制异步请求并发，最终返回所有请求结果。
> 16. 你平时会使用哪些 Coding 工具？
> 17. Codex 和 Claude Code 各自更擅长解决什么类型的任务？
> 18. 你之前做过 Web Coding 或技术方案设计吗？对这类技术方案熟不熟？
