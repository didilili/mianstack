## 原帖正文

> 之前面的，由于没特别详细记录，就都写一起了
>
> 1. 自我介绍
> 2. 问做过的项目
> 3. 问做过的研究的问题背景、现有方法、我们的发现、我的具体贡献
> 4. 从零写一个能用的 harness，至少需要哪些组件。我回答是至少要 agent loop, 工具，权限，todo write，可能还要一个上下文压缩就够了
> 5. 为什么 23 年 ReAct 就出现了，但是直到 25 年就流行起来。我回答基模能力、以及 25 年需求到了 Agent，然后被提示说还可能有别的原因，没想太出来
> 6. 简述一下手写一个 ReAct 怎么写。简单答了prompt 模板 + while 循环里 thought→action→observation、工具注册表、终止条件这些。[#牛客AI配图神器#](https://www.nowcoder.com/creation/subject/eb05ef0c3aad4981af85e1f84c8d3db3)
>
> 反问环节：
> 1. 后续有 3 面吗。答如果有都是 HR 面
> 2. 如果进去做什么。答可能和项目相关，比如 agent 的评测
> 3. 如何看待数据和训练，如何收集数据。答训练都是一键启动了，重点还是收集数据，数据是重要的，会考虑先做训练之外的事。数据更多会考虑合成模拟数据而非收集真实数据。
> 4. 有什么可以提升的。一面面试官答技术细节都了解，但回答可以更有条理和框架，像论文的背景、问题、方法、结果、贡献。
