> 二、项目一  
>
> 1. 这两个项目是学校的还是个人项目？  
> 2. 第一个项目你觉得解决了什么问题？面向什么用户？  
> 3. 你这个 Agent 和 Codex、Claude Code 有什么区别？  
> 4. 你是基于 Hermes 改的，还是从 0 到 1 自己搭的？  
> 5. 这个 Agent 是手撸的吗？还是借助 AI 写的？  
> 6. 你怎么做"人设初始化"这件事？怎么跟 AI 讨论需求、定位项目？  
> 7. 为什么选 Java 而不是 Python？对 Python 有什么意见吗？  
> 8. 搭建过程中遇到的最难的问题是什么？  
> 9. SSE 是干嘛用的？  
> 10. 为什么不用 WebSocket？SSE 和 WebSocket 底层有什么区别？  
> 11. RAG 在你项目里用来干嘛？  
> 12. Skill、MCP、Tools、Function Calling 分别是什么？解决什么问题？  
> 13. 自动化评测体系是怎么搭的？  
> 14. 你对大模型很感兴趣吗？未来想从事这方面工作吗？  
> 15. 现在大几？大二就出来实习了吗？  
>
> 三、项目二  
>
> 1. 这是个什么项目？  
> 2. 这是用 Java 做的吗？  
> 3. HashMap 底层是什么数据结构？  
> 4. 什么情况下触发树化？  
> 5. 扩容是怎么扩的？什么时候扩容？  
> 6. ConcurrentHashMap 用过吗？  
> 7. ThreadLocal 怎么用的？原理是什么？  
> 8. ThreadLocal 会导致内存泄露吗？  
> 9. Lua 脚本扣减库存是干嘛的？  
>
> 四、算法题  
>
> 1. 判断一个数是不是 2 的 N 次方（口述思路）  
> 2. 手撕最长无重复字符子串  
>
> 五、反问环节  
> 面试官问了下最快到岗时间和实习时长
