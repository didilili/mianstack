#### 正文要点

- 以简历深挖为主，后训练考察 GRPO、DAPO、PPO：GRPO 与 DAPO 的区别、组内样本全对或全错的问题及 DAPO 的处理、PPO 流程与四类模型的作用。
- 询问 Reward Model 和 Value Model 的常见结构与区别。
- Agent 部分要求列举使用过的框架与使用体验、核心模块，并说明 ReAct 与普通函数调用、工作流编排的差异。

> 主要是拷打简历，然后就是
> 1、问 GRPO / DAPO / PPO 相关基础：
> -GRPO 和 DAPO 有什么区别？

> -reward model 一般是什么结构？和 value model 有什么区别？
> 3、问 Agent 框架理解
> -用过哪些框架？说说场景体验
> - Agent 框架的核心模块有哪些？
> -ReAct 模式是什么？它和普通函数调用、工作流编排有什么区别？ #发面经攒人品#
