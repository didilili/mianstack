## 原帖正文

> 面试官：先自我介绍吧，挑一个你主导的 Agent 项目讲。
>
> 我：我做过一个风控归因 Agent，三级架构，主 Agent 负责编排……
>
> 面试官：为什么非得三级，单层不行吗？编排层单独拆成 Agent 图什么？
>
> 我：这个……主要是职责清晰，但说实话我当时没讲透为什么一定要拆。
>
> 面试官：主 Agent 跟子 Agent 上下文怎么传，怎么保证不漏掉关键信息？
>
> 我：（卡住）我就说了用摘要压缩，但他追问摘要把字段丢了怎么办，我答不上来。
>
> 面试官：那 Agent 上下文超长怎么压？
>
> 我：滑窗加动态摘要，长 query 也走摘要。
>
> 面试官：RAG 的召回率一般从哪些角度去提？父子文档索引解决啥？
>
> 我：切块用父子文档，小块检索大块返回。
>
> 面试官：手撕一下，把两个多层嵌套的 JSON 做深度合并，key 冲突且类型不同怎么办。
>
> 我：（写了个递归，类型不同的分支没处理好，写歪了）
>
> 面试官：评测 Agent 你怎么搭 benchmark？
>
> 我：按任务成功率加人工打分。
>
> 面试官：多个 Agent 之间上下文和状态怎么做到互不串？
>
> 我：（又卡了）说了用独立 session，但没讲清隔离边界。
>
> 面试官：GRPO 跟 PPO 在奖励归因上差在哪，为什么 GRPO 不用 critic？
>
> 我：GRPO 用组内相对优势，省掉价值网络……这块我准备得不熟。
>
> 我：反问下，团队现在 RL 用得多还是 SFT 多？
>
> 面试官：你连这都不知道？（反问中被怼）
>
> ……结果一面挂了。
