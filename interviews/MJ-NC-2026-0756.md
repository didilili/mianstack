## 原帖正文

> [#发面经攒人品#](https://www.nowcoder.com/creation/subject/c121d108a0d94e04b8821f14c3acadd5)[#面试问题记录#](https://www.nowcoder.com/creation/subject/3871fa77df8f40faa40474d054dbe5e3)
> 一、开场与意向确认
> 你是大三吗？实习周期大概能安排多久？
> 学校是否允许全职实习？能否解决异地租房问题？
> 你未来的技术方向偏向哪一块？
>
> 二、Java 后端基础
> 请描述一下 Spring Boot 的启动过程。
> Spring Boot 的启动入口函数是什么？
> 你了解 SingleFlight 框架吗？它和分布式锁有什么区别？
> CAS 乐观锁的原理是什么？存在哪些潜在问题？
> 在项目中，你更偏好使用哪种锁？为什么？
> 如果部署多实例，SingleFlight 框架会有什么问题？如何解决？
> 你写过哪些脚本？有没有遇到过 MySQL 索引失效的情况？哪些场景会导致索引失效？
> 为什么单表数据量过大会导致索引失效？
> 如果接口响应变慢，你会如何排查？
> 主线程如何判断子线程已经执行完毕？有哪些实现方式？
> 除了 CompletableFuture，还有其他方式吗？比如 join 函数你用过吗？
>
> 三、消息队列与中间件
> 你用过哪些消息队列？
> 请对比一下 RabbitMQ 和 Kafka 的区别及使用场景。
> Redis 支持哪些数据结构？底层有什么优化机制？
>
> 四、语言对比与项目经验
> 你同时掌握 Java 和 Python，它们之间有什么区别？
> 用 Java 对接 AI 大模型，相比传统 CRUD 项目有什么挑战？
> 你简历上写了 Spring AI，这个项目是你独立完成的吗？
> 你有服务器部署经验吗？具体怎么操作？
> 你用过 Docker 容器化部署吗？怎么用？
> 你了解 JVM 调优吗？具体有哪些参数或手段？
>
> 五、业务介绍与反问环节
> 你了解我们公司吗？有没有了解过我们的业务？
> 你入职后希望接触什么方向的业务？
> 你接触过基于 AI 的提效工具（如 Cursor）吗？
> 这次面试的结果什么时候能出来？后续还有哪些流程？
