#### 正文要点

- 开场围绕教育背景、技术栈、项目/竞赛/实习经历，以及 28 届学生是否能稳定长期实习展开。
- 多模态知识库项目追问视频帧采样比例、采用 OpenCV 处理关键帧丢失及像素差异阈值的依据；还要求说明内部文档结构化解析、由语言模型兜底清洗的流程和落地后的业务能力。
- 工程实践涉及 API 中转平台的业务场景、高并发下布隆过滤器、Redis 缓存、令牌桶与预热的分工，以及 Redis/MySQL 分层存储与重复请求处理。
- 分布式锁部分考察 Redis、AOP 与自定义注解实现的动机、具体使用场景和锁粒度；线上查询超时的排障还延伸至链路追踪、锁冲突、分片锁及缓存丢失的数据修复。
- 数据库追问涵盖按月分页缓解聊天记录深分页、分表与本地缓存的效果、索引下推和覆盖、联合索引范围条件、索引失效与 explain 分析；另有 CPU 持续高占用和慢 SQL 的完整排查路径。
- LLM/Agent 相关核心为混合检索 RAG：解释向量库、HNSW、BM25 与重排序的作用；并讨论在得物期间的 AI 内部提效工具（PR、审批、问题分配）。
- 结尾包括推荐冷启动、动态规划和双指针算法题，以及岗位以 Go 后端为主并附带 AI 知识库、内部提效工具工作的匹配度与技术栈转换意愿。
