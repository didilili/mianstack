## 原帖正文

> 日期：9.2  
>
> agentai面试官：agent方向  
> 面试净时长：约 45 分钟  
> 一、自我介绍  
> 1. 自我介绍  
> - 请做一个简单的自我介绍。  
> 	  
> 二、项目与技术八股  
> 2. 从 Workflow 迁移到 Skill  
> - 迁移前的 Workflow 是什么形式？Workflow 的每个节点是提示词还是代码？  
> 3. Skill 能力与流程  
> - 介绍一下 Skill 的核心能力和整体处理流程。  
> 4. MCP 在项目中的作用  
> - 该 Skill 背后调用的 MCP 是做什么的？  
> 5. 自动修复与安全边界  
> - Skill 可以直接帮助用户修复故障，还是目前只做到诊断？  
> 6. 模型与多模态能力  
> - Agent使用的是哪类模型？  
> - 有没有多模态场景，例如让用户上传截图？  
> 7. Skill 的定义与边界  
> - 该 Skill 是否主要用于定义处理流程，并把常见规则、边界、授权点和输出报告写清楚？  
> 8. 行业调研与方案比较  
> - 你调研过国内外类似的开源 Skill、组件或解决方案吗？  
> 9. MCP 调用链路  
> - 详细讲解一次 MCP 调用背后有哪些步骤。  
> - 一次 MCP 调用到底是谁发起、谁执行？  
> - 模型、Agent、MCP Client 和 MCP Server 分别承担什么职责？  
> 	  
> 三、Agent 上下文与 Memory  
> 10. Agent 上下文的组成  
> - Agent 的上下文一般由哪些内容组成？  
> 11. 上下文过长的处理  
> - 上下文过大时，如何保证多轮对话能够继续？  
> - 处理上下文过长有哪些常见策略？  
> 12. 上下文压缩策略  
> - 上下文压缩时会对所有内容一视同仁，还是会侧重不同内容？  
> - 具体应该如何压缩？  
> 13. 不同 Agent 框架的上下文机制  
> - 你了解 OpenCode、Claude Code、Codex、DeepSeek 等框架在上下文处理上的差异吗？  
> 14. 当前 Skill 对 Memory 和第三方知识的使用  
> - 该 Skill 使用了 Memory 或第三方知识吗？  
> 15. Memory 的检索与更新  
> - Memory 应该如何检索和更新？  
> - 例如，用户从北京搬到上海后，系统应该如何处理原来记录的北京居住信息？  
>
