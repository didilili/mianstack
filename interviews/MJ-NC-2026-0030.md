#### 正文要点

- 约 1.5 小时，按项目/实习、算法、AI Coding、反问展开；项目表达被要求从目标、最大挑战、思考和解决方案讲起。
- Agent 项目集中在 Memory 架构：三层存储原因、上下文、格式化输出、Token 成本管控、SkillRouter 设计、Milvus 召回率和关键词匹配测试及经济性。
- 代码审查项目从 PR 提交到 Review 意见生成的链路，被追问五个 Agent 的编排与分工、单 Agent 是否可替代、Router Agent 和三个并行 Agent 的设计。
- 并发部分考察多 PR 处理、同一 PR 多作者的竞态问题；后续延伸到跨线程投放任务、gRPC、竞态条件。
- 编程为链表去重，AI Coding 为检测图片 Alpha 通道。


#### 全文原文（原文）

> 介绍面试流程（简历上项目，实习，算法，AI Coding，反问，总结）  
>
> 自我介绍  
>
> 从你简历上实习，项目中，挑一个你认为对你提升最大的项目来讲一下，从这个项目的：目标，应对的最大的挑战，以及你对这个挑战是怎么思考并解决的？（实习项目，一个Agent项目  
>
> 刚才我们说的是设计层面上的，如果从技术层面上来讲，你设计的这个Memory架构，使用的这些技术就会对这个项目有什么提升和优化？以及未来你的优化方向可能哪些？  
>
> 那做这个Memory架构肯定是为了更好的去配合大模型吧，如果对于配合大模型来说，比如对它的上下文，格式化输出，以及一些token成本的管控，在这方面你有没有什么思考  
>
> 那么你在设计这个项目的Memory模块的时候，为什么会考虑采用这三层来存？  
>
> 看到你的这个里面做了一个SkillRoutor，可以讲讲这个SkillRouter具体是怎么做的吗？  
>
> 你的这个项目到现在有进行过测试吗？比如说一些Milvus的召回率，关键词匹配成功率这些方面的，以及你会怎么去做一些测试？你怎么去做一些经济方面的考量  
>
> 整个后端架构是你自己完成的吗？有没有技术导师给你线设计架构？还是都是你完成的  
>
> 看到你下面还有两个项目，挑一个你觉得最有成就感的讲一下  
>
> 好的，那你依然还是从目标，挑战和解决方案这三个方面，以及你当时是从什么方面考虑？会去做这样一个项目呢？  
>
> 这个项目你目前还在使用吗？在使用过程中你有没有发现一些错误？以及未来你有没有一些改进思路？  
>
> 你可以讲一下这个项目从你提交PR开始到Review意见生成的整个流程吗？  
>
> 看到你的这个项目分成了5个Agent，你设计怎么编排他们的？另外你是怎么去考虑这五个Agent的分工，使用一个Agent不可以吗？  
>
> 你这个RouterAgent设计怎么做的？下面并行跑的这三个Agent又是设计的  
>
> 现在假如是有多个PR的话，你这个项目怎么办？现在可以处理吗？还是要等一个PR完成后再处理下一个？  
>
> 如果一次PR有多个作者，可能会涉及到并发问题，你又是怎么设计的？或者如果你没设计的话现在思考一下这个可能会怎么设计？  
>
> 上面的问题你下去以后再思考一下，我看到你好像还有两个项目，一个高并发服务器框架一个高性能内存池，挑一个讲一下，还是从目标，挑战，解决方式这三个方向来说  
>
> 这个项目中你怎么解决跨线程投放任务这样一个问题？  
>
> 你有了解过现在业内成熟的其他的解决方案吗？比如说gRPC什么的？  
>
> 你的简历上写的会处理一些竞态条件，你能详细说一下这个项目中哪里会出现一些竞态条件吗？
