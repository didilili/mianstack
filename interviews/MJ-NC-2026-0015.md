#### 正文要点

- 测试基本功覆盖 Pytest 的使用与作用域、测试数量和用例设计、基于文章发布接口的角色与内容测试，以及接口测试和 UI 测试的比较。
- 自动化与工程化考察 Playwright 用例耗时、UI 测试稳定性和维护成本、CI/CD 阶段、Allure 报告与 Docker 在 CI 中的用途。
- 后端与稳定性题包括 token/session 选择、Redis 限流算法、Redis 与 MySQL 的使用边界、缓存一致性、旁路缓存与延迟双删。
- 大模型相关部分直问 AI Coding 工具、Harness 约束规则、AI 生成代码审查、幻觉处理以及 RAG 项目。
- 手撕题为 LeetCode 410“分割数组的最大值最小化”；作者反馈面试超过一小时，项目和基础细节追问较深。
