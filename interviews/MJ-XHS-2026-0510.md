## 原帖正文

> 主包面试沟通了不少岗位，整理了一些面试高频问题分享一下。
> 如果你在面试，不论是开发岗位还是AI岗，都有很大的概率会遇到AI coding的面试题。
> 下面是我总结的遇到的问题和回答方式，大家可以参考一下。
> 1、AI coding的使用
> 主包面试过程中有被问到有没有用AI coding，怎么用，代码覆盖率怎么样之类的问题。
> 如果你没用过AI coding，很建议学着用一下。
> 可以选择Claude code 或者 codex，如果只是个人学习可以用Claude code接deepseek等模型，价格便宜很多。
> 我用的是vs code + claude code + deepseek，也订阅了chatGPT，赠送有codex额度。
> 在回答有没有使用AI coding的时候，我会补充我使用的具体是哪类工具，比如CC、cursor、codex等。
> 怎么用这个问题能够体现出你对AI coding的使用深度，这个问题从几个方面回答。
> （1）skill的使用，可以和面试官聊聊你常用的skill和应用场景，比如frontend-design、superpowers，结合自己的使用习惯回答就行。
> （2）claude.md文件/agents.md文件的维护，这类文件是给agent看的项目说明，会被完整加载到对话中。
> 但文件内容不是越多越好，而是要尽量精简，黄金线是200行。
> 讲好怎么去维护这个Markdown文件能够体现出你在大工程开发过程中的AI coding经验。
> （3）测试，单测在工程研发过程中一直在被强调，而在AI coding的时代，agent可以直接自动化地跑单测验证AI coding代码的正确性，所以单测变得更加重要。
> AI虽然可以帮忙写一些单测，但是有些边界或特殊case AI 未必都能覆盖，需要有线上实践经验或者工程直觉才能想到，所以补充单测也很重要。
> 另外可以将写代码和验证工作分别交由不同的模型来做，并让它们持续优化，也就是反思机制的思想，这样也能提升代码质量。
> （4）多任务执行，借助git workTrees通过多终端并行处理，做完后在各个终端提交，然后让agent合并并解决冲突。
