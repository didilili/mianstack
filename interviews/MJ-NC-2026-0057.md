#### 正文要点

- 自我介绍后限时 3 分钟介绍项目，整体以 Agent 运维场景题为主。
- 询问系统发生网络抖动而非真实故障时，Agent 如何辨别；也问 Agent 排障建议与实际不符时的处理，即大模型幻觉的兜底。
- RAG 部分包括检索准确率的统计方法与知识库系统全链路设计。
- 仅穿插 Redis 三剑客和 MySQL 选择 B+ 树两项基础问题；作者称另有两道场景题已忘记。


#### 全文原文（原文）

> 1.自我介绍  
> 2.3分钟介绍项目  
> 3.如果系统出现了网络抖动，而不是它真正出现了故障，那这时候你的agent该怎么判断这是因为网络抖动而出现问题  
> 4.如果AI agent 给出的排障建议，出现与实际不符的情况，该怎么办（就是问大模型幻觉的处理）  
> 5.RAG检索的准确率，是怎么统计的  
> 6.RAG知识库系统全链路设计  
> 7.Redis三剑客  
> 8.Mysql为什么使用B+树  
> 9.反问
