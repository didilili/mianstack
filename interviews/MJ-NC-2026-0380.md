## 原帖正文

> 小鹏二面  
>
> 流程：自我介绍 → 实习深挖（大模型应用）→ AI Coding（Claude Code vs Dify）→ JVM → MySQL → AI Coding（编程助手使用）→ 项目（MyRPC）→ 个人方向 → 反问。  
>
> 面试官问题  
> 一、实习深挖（大模型应用）  
> 你先简单自我介绍一下。  
> 能展开来讲一下你在公司大模型应用里边的一些工作吧。能不能再具体讲一下，特别是跟技术有关的？  
> 展开讲一下你怎么解决上下文过长、幻觉这个问题？你是怎么解决的？  
> 我感觉你在实习期间做后端的研发，主要是做 Dify 的工程（二开）是吧？（追问）二开的话你们会涉及到比较多的工具开发，比如搭 MCP、搭一些官方的 Agent 或者智能体，对吧？  
> 你自己有没有用 Claude Code？你觉得 Claude Code 跟这个（Dify）有什么区别，对比下来怎么样？  
> 二、JVM  
> 我们回过头来聊一下一些基础的技术，讲一下 JVM 内存区域（线程私有部分、共享部分、方法区的演进）？  
> 三、MySQL  
> 慢查询是怎么去发现排查以及做什么优化手段？  
> 讲一下 InnoDB 索引的原理（B+ 树、聚簇索引/非聚簇索引、回表）？  
> 分布式锁实现原理是怎么样的？以及是如何避免死锁？  
> 四、AI Coding（编程助手使用）  
> 在实习过程或者做项目过程中，自己在 AI coding 方面有没有自己的一些了解或研究？  
> 五、项目（MyRPC）  
> 你自己动手写了一个 MyRPC，是基于哪个开源的参考去写的？（追问）这个过程写这个 demo 之后，给你什么新知识吗？或者对你后续的一些项目开发有什么帮助没有？  
> 六、个人方向  
> 我看到你本科跟硕士都学的人工智能，然后你做的是后端的一些工程，对吧？你们学的人工智能主要是学哪方面？  
> 反问  
> 可以麻烦您先简单介绍一下您具体做的就是哪一块业务？（面试官回答）中心统招，面试官是中心其中一个部门的研发副总监。小鹏三大研发中心：自动驾驶、智能座舱，以及这个中心（覆盖除前两者以外的所有开发）。涵盖整个汽车生命周期：工厂（机械生产排程、物流、供应链、零部件管理、产线）、研发系统（车型研发）、售前（CRM 渠道推送、营销事件）、售中（下单提车、汽车金融、汽车保险）、售后（维修保养系统、派单、销售管理、后汽车市场：三千多个充电站的物联网、无人值守、强依赖云平台物联网与计费；机器人 Iron 的云平台；企业内部提效系统如报销、演示；AI 中台——从 2023 年开始用 Copilot 编码，2024 下半年至 2025 年要求所有业务部门用 AI 提效，业务领域内有预审、OCR 识别、图片识别等场景）。  
> AI 方面的这些，其实有专门的团队，不是说传统后端去兼顾的对吧？（面试官回答）相当于在实习公司的基础平台一样，业务领域自己要用上的话，可以快速在平台里面创建一些大模型的 token（账号密码类似），就可以在业务里使用，不需要各业务自己到处去接外面的那些模型。  
> 传统后端 Java 这一块，用到的技术栈大概是哪些方面？（面试官回答）基本都是 Spring Boot + MyBatis + Redis，大部分项目用 Kafka，有一些项目用 ES；还有限流熔断组件。整个中心业务比较大，涵盖 C 端、B 端以及一些核心可用的（如支付中心，整个集团的充电支付、买车支付等都在这里）。
