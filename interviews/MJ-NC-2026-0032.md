#### 正文要点

- 作者为大二候选人，4 月投递、6 月中技术面，7 月初进行主管面，7 月中旬获得 offer；流程中笔试豁免但综合测评进行了两次。
- 一面约 50 分钟：专业课和基础包括 TCP 三次握手与“两次不行”的原因、C 临时变量存储区，以及 CTF 经历；随后深挖基于 ReAct 和改造 RAG 的 Agent 项目。
- 项目追问不只问架构，还确认候选人是否实际参与实现。作者坦言主要负责外围服务、没有直接编写 Agent 核心，但熟悉整体设计。
- 代码题为拓扑序；面试官评价其现场实现效率不足，反映图算法和数据结构基本功仍是 Agent 岗的硬性考察。
- 二面/主管面仍偏技术：教育背景、数字逻辑/组成原理/操作系统/编译原理与数据结构，及 C 语言编译链路、编译单元到目标文件的过程。
- 第二轮围绕 Computer Use Agent 的背景、结构、ReAct + 改造 RAG、以及 RAG、Skill、MCP 的定义与关系展开；反问得到的建议是补充业界 Agent 框架学习，文中举例 Claude Code。
