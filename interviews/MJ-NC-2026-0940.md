> 一、开场与岗位匹配
>
> 1. 自我介绍。
>
> 2. 你的经历基本集中在 AI 和相关应用开发上，传统服务端开发知识有储备吗？数据库、缓存、消息队列和计算机网络这些方面，你有多少了解？这些传统后端知识是否做过专门准备？
>
> 二、RAG 实习项目
>
> 1. 介绍一下实习中参与的 RAG 系统。
>
> 2. 基于你的理解，一个完整的 RAG 系统由哪些部分组成？
>
> 3. 在数据清洗和文档切分环节，你具体做了哪些工作？
>
> 4. 你采用了怎样的切分策略？如何兼顾片段长度与语义结构？
>
> 5. 表格和跨页表格是怎样处理的？
>
> 6. 为什么向量能够表达语义，并用于语义相似度检索？
>
> 7. 向量检索过程中使用的具体检索算法是什么？
>
> 8. BM25 的计算过程和主要考虑因素是什么？
>
> 9. RRF 的计算过程是什么？
>
> 10. 多路召回的结果为什么需要融合？RRF 如何根据排名完成融合？
>
> 11. 你调研了多种 PDF 解析工具，比较它们效果时主要关注哪些指标？
>
> 12. 为什么不同业务场景会选择不同的 PDF 解析方案？
>
> 三、Agent 基础与工具调用
>
> 1. Agent 在大语言模型的基础上增加了哪些能力或组件？
>
> 2. 你怎样理解 Agent 的记忆、工具、观察和循环？
>
> 3. Agent 具体是怎样调用一个工具的？
>
> 4. 大模型本身只输出文本，为什么它还能执行工具或命令？完整的调用链路是什么？
>
> 5. Agent 的效果应当如何调优和评估？
>
> 四、上下文工程（Context Engineering）
>
> 1. 实习中的 Context Engineering：背景是什么，你具体做了什么？
>
> 2. 为什么 Agent 的上下文过长后，模型输出会不符合预期？
>
> 3. 如果要为一个 Agent 编写提示词或设计上下文，上下文通常由哪些部分组成？
>
> 4. 你为什么把读文件和写文件任务拆给 Sub-Agent？
>
> 5. Sub-Agent 的结果如何持久化？主 Agent 如何按需获取细节？
>
> 6. 这种上下文治理方案减少了什么，又可能牺牲什么？
>
> 五、Agent 实习项目
>
> 1. 介绍实习的业务背景，以及你具体负责的工作。
>
> 2. 为什么需要构建整份文档的结构树？具体怎么构建的？结构树中有哪些层级和节点类型？
>
> 3. 这个项目中，Agent、Workflow 和大模型分别承担什么职责？
>
> 六、Agent 学习项目
>
> 1. LangChain、LangGraph 这类 AI 开发框架对开发者起到了什么作用？
>
> 2. LangChain 如何统一管理上下文、工具调用、记忆和状态流转？
>
> 3. 使用框架与自行搭建 Workflow 相比，各有什么优缺点？
>
> 七、个人思考
>
> 1. 实习过程中有没有让你印象深刻的问题？你是怎么解决的？
>
> 2. 你认为当前通用 Agent 的能力边界在哪里？为什么垂直领域 Agent 更容易落地？
>
> 3. AI 技术发展很快，你日常如何学习和跟进新技术？
>
> 八、公司与求职动机
>
> 1. 你对东方财富公司有什么了解？
>
> 2. 为什么投递东方财富？
>
> 3. 你对该岗位的业务方向和技术要求有什么理解？
