> # 钉钉二面
>
> > 流程：自我介绍 → AI 实习项目深挖（智能问答 / 评测 / 大模型训练）→ AI Coding 工具使用 → MCP / Skill → 反问。
>
> ## 面试官问题
>
> ### 一、自我介绍与 AI 实习项目深挖
>
> 1. 请自我介绍一下。
> 2. 现在的 AI 这块有怎样？接触过哪些？
> 3. 介绍一下你之前做的 Agent。
> 4. 有没有做过功能开发，或者做过模型训练、模型微调？
> 5. 基于大模型上面的功能开发做过吗？
> 6. 像这种智能问答属于你这个问题的范畴吗？简单介绍一下你做的智能问答是什么，怎么实现？
> 7. 用的是什么模型？
> 8. 当时你们怎么去评测这个问答效果的好与坏？（追问）怎么去做的评估？
> 9. 行业里用模型做评测是很常见的技术，但同模同样的模型去做评测比较少见，你们的设计考虑是什么？（追问）你们在评估的过程当中发现了有哪些问题？
>
> ### 二、大模型原理
>
> 1. 能介绍一下 V3 背后的大模型架构，有了解过吗？
> 2. 在这个专业里面，自己有没有去训练过、戳过小模型？
> 3. 有了解过一个模型是怎么训练出来的吗？
> 4. 如果今天我们想自己去训练一个模型出来，分为哪些步骤？需要关注的点是什么？
> 5. 梯度是怎么计算的？
> 6. 我们在算梯度的时候可能会出现哪些问题？
>
> ### 三、AI Coding 工具
>
> 1. 现在你使用的一些 AI coding 工具是什么？（追问）为什么是（这些工具）？（追问）你现在是怎么去使用的？比如你要开发一个项目。
> 2. 在开发的过程当中，我们如何能够让他尽可能自主地去完成一些独立的模块，包括开发、测试，能够直接得到一个可产出的产物，有哪些办法？
>
> ### 四、MCP 与 Skill
>
> 1. MCP 跟 Skill 有什么区别？
> 2. 自己有去搭建过 MCP Server 吗？
> 3. Skill 自己有开发过吗？
>
> ## 反问
>
> 1. 可以麻烦简单介绍一下您所在的小组大概做的业务是哪一块？（面试官回答）钉钉两块业务：(1) 开放平台，包括整个钉钉的 API、开发者成果、开发工具相关，解决的是钉钉被集成的方案；(2) 其中还带了一个行业线，主要做软硬一体 + 云视觉质量的解决方案。
> 2. 您做的可能跟传统后端有一定差异？（面试官回答）现在没有什么前后端简单区分，都是全栈。
> 3. 您刚才着重讨论的是 AI 方面，也想问一下您平时用到的主要技术栈、工具、能力大概是哪些方面？（面试官回答）从语言角度上讲，Python、Java；后端和前端都是比较主流的，像 Java 语言或者一些前端框架（如 React / Vue）；常用开发工具有 Cursor、Claude Code、Gemini、Windsurf、Cline 等，且同时都在用。
> 4. 这些 AI coding 工具在您的工作中大概扮演了怎样的角色？（面试官回答）工作其实都是借助这些 AI coding 工具去完成的，现在可能不能仅仅把它当成工具了，其实是我们工作的一部分。
> 5. 这些工具这么强大，我们开发者的优势可能体现在哪些方面？（面试官回答）第一是洞察 / 判断力，AI 对业务的判断、对未来的判断很难有明确的判断力，所以洞察和判断力是取代不了的；第二，我们其实跟 AI 之间已经形成一种密切的合作关系，AI 能解决单点问题，但怎么调度多个 AI、多个 AI 系统之间一起合作解决复杂问题、长任务，还需要人在过程中帮它做一些勾结；第三，如果 AI 所有机械都做完了，人与人之间的温度、情感上的一些连接，AI 也取代不了。
