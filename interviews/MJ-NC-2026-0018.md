#### 正文要点

- 实习经历部分追问批量导入测试数据和结果、卡密加密，以及订单核销中如何防止请求参数被拦截篡改。
- AI 学习资源生成项目是核心：要求介绍架构与难点，说明多个 Agent 各自所用模型及多 Agent 的必要性，并讲清 Python 的作用和练习题 RAG 设计。
- 拼团项目追问项目难点、QPS、MQ 使用场景、Redis 的必要性；进而延伸到 AOP 动态代理、AOP/事务失效条件与替代技术选型。
- Java 基础包括垃圾回收、双亲委派、类加载、单例模式、缓存三大问题；另有两根不均匀绳子测量 45 分钟的智力题。
- 反问围绕部门业务和技术栈。作者说明面后次日收到感谢信。
