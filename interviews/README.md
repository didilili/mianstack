# 面经目录

本目录保存面经的来源信息、岗位语境和可公开展示的来源材料。每个文件使用稳定的 `MJ-NC-*` 或 `MJ-XHS-*` 编号。

- 作者、原始链接、发布时间、岗位语境和正文以当前文件为事实来源。
- 可公开展示完整来源材料时，正文统一使用 `## 原帖正文`，有实际内容时再增加 `## 图片` 和 `## 有价值评论`；不要写采集位置、迁移说明或空占位章节。
- 仅提交有公开来源且适合再发布的内容；没有再发布依据时，优先保留链接、必要的有限引用和自己的整理说明。
- 字段结构见 [`schema/README.md`](../schema/README.md)，最小写法见 [`examples/interview.example.md`](../examples/interview.example.md)。
