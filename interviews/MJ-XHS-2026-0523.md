## 原帖正文

> 这周面了 3 家 AI 公司
> 来聊聊我金三银四第二周的面试情况。
>
> 这周一共面了 3 家，岗位都是大模型应用开发 / Agent 开发方向。目前 1 家已经过了一面。
> ---
> 这周面下来最大的感受：很多人以为 Agent 岗位主要考模型和 Prompt，但实际面试更关注工程落地能力。
>
> 几乎每场都会问到：
>
> 1️⃣项目架构怎么设计？Agent 系统怎么拆分？Planner / Tool / Memory 怎么分层？
> 2️⃣Memory 怎么搞？短期、长期、用户画像各怎么处理？
> 3️⃣延迟、成本、效果怎么平衡？Token 成本、推理延迟、RAG 召回策略怎么权衡？
> 4️⃣RAG 效果怎么评估？召回率、准确率、线上怎么验证？
>
> ---
> 几点收获：
> 1️⃣Agent 岗不只考模型理解，很多时候其实是在考后端工程 + 系统设计。
> 2️⃣项目介绍要有完整逻辑：业务背景 → 技术方案 → 效果验证。讲清楚这三件事。
> 3️⃣拉开差距的地方不是调 API、写 Prompt，而是系统设计和工程落地的能力。
>
> ---
> 接下来打算重点准备：继续打磨项目介绍，整理 Tool Calling / Memory / RAG 的高频追问，每场面试做一次结构化复盘。
>
> 说个好笑的事——这周特意准备了很多 OpenClaw / Skills / Agent 框架相关的内容，结果三场一场都没问到。
>
> 如果你最近也在面大模型应用 / Agent 岗，欢迎交流。我会继续记录在职转行大模型的面试过程。
