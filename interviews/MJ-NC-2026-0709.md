## 原帖正文

> - 请介绍一下你的技术背景，重点谈谈你参与过的 Agent 相关工作。
> - 选一个你最熟悉的 Agent 项目，讲讲它解决了什么业务问题、整体方案如何设计，以及上线后的实际效果。
> - 你怎么理解 Agent Harness？在项目中会怎样搭建它？和直接使用托管式 Agent 服务相比，各自的差异是什么？
> - 设计一个多 Agent 系统时，你会怎样划分角色和协作边界？它相比单一 Workflow，适合解决哪些问题？
> - 中心调度 Agent 如何把复杂目标拆成子任务、分配给不同 Agent，并判断结果是否完整、如何汇总？
> - Agent 的记忆为什么有人选择用 Markdown 文件维护？它和 RAG 在用途、检索方式及更新成本上有什么区别？
> - 如果要为 Agent 建设知识库，你会怎样处理数据接入、切分、检索、更新和效果评估？
> - Agent 沙箱需要隔离哪些资源和操作？你会怎样设计权限控制，避免 Agent 越权或造成不可逆影响？
> - 在没有人工审核的自动执行场景中，你会如何控制 Agent 的错误率和影响范围？怎样设计验证、回滚、限额与监控？
> - 大模型的工具调用大致经历哪些步骤？选择或设计工具时，你会如何权衡能力边界、调用成本、可靠性和安全性？
> - MCP 解决了什么问题？如果 MCP 工具调用超时、失败或返回异常，你会怎样设计重试、降级和错误反馈？
> - Skill 和 MCP 在加载及调用方式上有什么不同？当配置文本长度相近时，Token 开销会受哪些因素影响？你会用什么标准判断一个 Skill 是否有效？
> - 请解释 KV Cache 在大模型推理中的作用，以及它对生成速度、显存占用和长上下文有什么影响。
> - 如果要用 AI Coding 构建一个支持多个实例并发工作的系统，你会怎样设计任务隔离与协作流程？如何编写首轮提示词，让 Agent 先产出可评审的 Spec？
> - 你平时怎样把 AI Coding 用在开发中？遇到 Agent 生成的代码有问题时，通常如何定位和修正？在整个流程里你最重视哪个阶段？
